# Карта регистров Modbus

Подтверждена рабочей программой `C30 Servo GUI v5` (Windows) — то есть это не
гипотеза с шины, а то, чем реально управляли приводом.

## Адресация параметров

Параметры `P-nnn` отображаются в holding-регистры по правилу:

```
адрес = nnn        (в PDU, для pymodbus)
4xxxx = 40001 + nnn (в «человеческой» нотации)
```

Правило действует и для «1-segment» параметров: `P-181 -> 0x00B5` (181).
Раньше это было открытым вопросом — `P-181` его закрыл.

| Параметр | Адрес   | Назначение                          | Единицы |
|----------|---------|-------------------------------------|---------|
| `P-004`  | `0x0004`| режим управления, 0..8              | —       |
| `P-076`  | `0x004C`| скорость JOG                        | об/мин  |
| `P-098`  | `0x0062`| принудительное разрешение привода   | 0/1     |
| `P-181`  | `0x00B5`| адрес привода на шине Modbus        | —       |
| `P-207`  | `0x00CF`| номинальные обороты мотора          | об/мин  |

## Регистр команд

| Команда                             | Значение |
|-------------------------------------|----------|
| Выход из JOG / останов              | `0x0000` |
| Разрешён, удержание нулевой скорости| `0x1234` |
| Вперёд                              | `0x2222` |
| Назад                               | `0x1111` |

Адрес — `0x1010`.

## Регистры состояния

| Адрес    | Что                                  |
|----------|--------------------------------------|
| `0x1000` | фактическая скорость вала, об/мин    |
| `0x101A` | код аварии                           |
| `0x101F` | абсолютное положение, младшее слово  |
| `0x1020` | абсолютное положение, старшее слово  |

Положение — 32-битное знаковое, младшее слово первым.

## Поправка к раннему дампу

Первоначальный захват шины давал регистр команд `0x1011` и «назад» = `0x110D`.
Верные значения — `0x1010` и `0x1111`. Несимметричность «вперёд/назад» в том
дампе (`0x2222` против `0x110D`) была признаком ошибки захвата, и так оно и
оказалось: настоящая пара `0x2222` / `0x1111` симметрична.

Вывод на будущее: значения, снятые с шины, проверяйте на симметрию и
закономерность — кривой байт виден по тому, что число «выбивается из ряда».

## Пароль

`P-000` — operating password, по умолчанию `315`. Для `P-001`, `P-002`, `P-099`
нужен `385` или `316`.

Без нужного пароля запись **проходит молча**: Modbus отвечает «ок», значение не
меняется. Всегда читайте записанное обратно — `examples/mb.py write ... --verify`.

## Что даёт наличие 0x101F

Регистр абсолютного положения был недостающим звеном для программного контура
позиционирования: теперь `ServoDrive.move_to()` работает без дополнительной
настройки — адрес стоит по умолчанию.

Ограничения прежние и честные: контур замыкается через RS-485 с циклом в
десятки миллисекунд, так что это инструмент наладки и медленных доводок.
Именно так работает и `C30 Servo GUI v5` — её собственный README называет это
«supervisory loop, NOT hard real-time».
