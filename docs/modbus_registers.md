# Карта регистров Modbus (черновик)

Источник: захват обмена с приводом. Значения зафиксированы «как есть», без
подтверждения по документации производителя.

## Адресация параметров

Параметры `Pnnn` отображаются в holding-регистры в нотации 4xxxx:

```
4xxxx = 40001 + nnn      ->      nnn = 4xxxx - 40001
```

Проверка: `40099` -> `P098` (совпадает).

| Modbus (4xxxx) | Параметр | Смещение (0-based) | Назначение                | Пример значения |
|----------------|----------|--------------------|---------------------------|-----------------|
| 40077          | P076     | 76 (0x4C)          | скорость                  | `100`           |
| 40099          | P098     | 98 (0x62)          | ? (уточнить)              | `1`             |

## Регистр команд

Адрес `4113` = `0x1011`. Запись управляющего слова:

| Команда | dec    | hex      |
|---------|--------|----------|
| Вперёд  | `8738` | `0x2222` |
| Назад   | `4365` | `0x110D` |
| Стоп    | `0`    | `0x0000` |

## Открытые вопросы

- Модель привода / контроллера — нужна для сверки с официальной картой регистров.
- Что именно задаёт `P098` (значение `1`).
- Единицы `P076`: об/мин, Гц x0.1 или проценты — `100` неоднозначно.
- Функция записи: 0x06 (single) или 0x10 (multiple)?
- Slave ID, скорость порта, чётность.
