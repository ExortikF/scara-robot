# Движение по положениям: S7-1200 + сервопривод (руководство C30)

## Что есть в S7-1200

Технологический объект **TO_PositioningAxis** («Ось позиционирования») + блоки PLCopen:

| Блок               | Назначение                                        |
|--------------------|---------------------------------------------------|
| `MC_Power`         | разрешение оси (Servo ON)                         |
| `MC_Home`          | привязка нуля / поиск базы                        |
| `MC_MoveAbsolute`  | выход в **абсолютную** позицию                    |
| `MC_MoveRelative`  | смещение на заданную величину                     |
| `MC_MoveVelocity`  | вращение с заданной скоростью                     |
| `MC_MoveJog`       | толчковый режим                                   |
| `MC_Halt`          | останов по профилю                                |
| `MC_Reset`         | сброс ошибок оси                                  |
| `MC_CommandTable`  | **таблица заданий** — до 32 шагов, выполняются подряд |

`MC_CommandTable` (объект `TO_CommandTable`) — это и есть «движение по положениям»:
таблица шагов вида *Positioning Absolute / Positioning Relative / Velocity setpoint /
Wait*, каждый со своей позицией, скоростью и временем. Запускается одним вызовом.

### Требования к железу

- Выход **PTO** (импульсы + направление) — нужен CPU с **транзисторными** выходами
  (DC/DC/DC) либо сигнальная плата SB 1222/SB 1223. На CPU с реле PTO не работает.
- До 4 осей PTO на CPU (FW 4.x).
- Частота импульсов: до 100 кГц на встроенных выходах, до 200 кГц на SB 1222.

### Важное ограничение для SCARA

Motion Control S7-1200 — **пооосный**. Нет интерполяции между осями, нет кинематики,
нет объекта «робот». `MC_CommandTable` тоже работает по одной оси.

Для SCARA это значит:
- PTP-перемещения (каждая ось едет независимо в свою точку) — делаются штатно;
- прямая/дуга в декартовых координатах и обратная кинематика — **пишутся вручную**
  в PLC (пересчёт XY -> углы q1/q2, разбивка траектории на точки, синхронный старт осей);
- «из коробки» кинематика есть только у S7-1500T (Kinematics TO).

## Сопряжение с приводом (руководство C30)

Привод принимает позиционное задание **только импульсами** по входам PULS+/PULS-,
SIGN+/SIGN- (стр. 37, п. 4.2; стр. 46, п. 4.3.1). Внутреннего многопозиционного
режима (PR / multi-segment position) в руководстве нет — в оглавлении такого
раздела нет, `P-004` описывает только режимы 0..5:

| P-004 | Режим                                                  |
|-------|--------------------------------------------------------|
| 0     | позиционный (по умолчанию)                             |
| 1     | скоростной                                             |
| 2     | моментный                                              |
| 3     | позиционный/скоростной (переключение входом CMODE)     |
| 4     | позиционный/моментный (CMODE)                          |
| 5     | скоростной/моментный (CMODE)                           |

> Диапазон `P-004` заявлен как 0..8, но значения 6..8 в руководстве не описаны —
> стоит уточнить у производителя, нет ли там недокументированного внутреннего
> позиционирования.

### Параметры под связку с PTO S7-1200

| Параметр            | Значение | Комментарий                                   |
|---------------------|----------|-----------------------------------------------|
| `P-004`             | `0`      | позиционный режим                             |
| `P-035`             | `0`      | **импульс + направление** — формат PTO S7-1200 |
| `P-036`             | `0/1`    | инверсия направления счёта                    |
| `P-028`/`P-029`     | —        | числитель эл. редуктора = `P-028*10000 + P-029` |
| `P-030`             | 1..32767 | знаменатель эл. редуктора                     |
| `P-037`             | 0..12    | логика/фронт входных сигналов                 |
| `P-038`/`P-039`     | 2 / 0    | фильтры импульса и направления                |
| `P-040`             | 0..5000 мс | экспоненциальное сглаживание задания        |

Электронный редуктор задаёт, сколько импульсов PLC = один оборот мотора; через него
в TIA Portal согласуется «импульсов на оборот» в конфигурации оси.

## Связь с картой Modbus

Нумерация `P-0nn` («0-segment parameters») совпадает с ранее снятой картой
регистров: `4xxxx = 40001 + nn` (см. [modbus_registers.md](modbus_registers.md)).
Modbus здесь годится для настройки/диагностики, но не для позиционирования —
траекторию гонит PTO.
