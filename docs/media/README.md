# Куда класть фотографии и видео

Файлы отсюда показываются на главной странице проекта. Имена важны —
на них ссылается корневой `README.md`, поэтому называйте ровно так.

| Файл | Что снять | Как показывается |
|---|---|---|
| `обложка.jpg` | Манипулятор целиком на тележке. Горизонтально, свет спереди | Первая картинка на странице, самая заметная |
| `слежение.gif` | Экран программы: рука двигается, зелёное звено идёт следом | Главное доказательство, что оно работает |
| `окно.png` | Снимок окна управления целиком | Раздел «Как это выглядит» |
| `схема_стенда.jpg` | Шкаф с приводами, переходник RS-485, проводка | Раздел «Железо» |
| `рука_камера.jpg` | Вид с камеры сверху с наложенным скелетом | Раздел «Как это работает» |

## Как сделать GIF из видео

Снимите видео на телефон (5–10 секунд достаточно), положите рядом и:

```bash
ffmpeg -i видео.mov -vf "fps=12,scale=720:-1:flags=lanczos" -loop 0 docs/media/слежение.gif
```

Если `ffmpeg` не стоит: `brew install ffmpeg`.

GIF тяжелее видео. Держите его в пределах 10 МБ, иначе страница будет
открываться долго. Помогает `fps=10` и `scale=600:-1`.

## Видео целиком

GitHub проигрывает видео прямо на странице, но только если файл
загружен через веб-интерфейс: откройте `README.md` на сайте, нажмите
карандаш и перетащите файл в текст — GitHub сам вставит ссылку.
Файлы в репозитории так не проигрываются, поэтому большие видео лучше
не коммитить.

## Чего не хватает

Пока ни одного файла нет — на странице вместо картинок стоят пометки
«нет файла». Как положите, они появятся сами, менять `README.md` не надо.
